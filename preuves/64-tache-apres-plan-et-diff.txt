# Add GET /rooms/:id/availability endpoint

## Goal
Implement `GET /rooms/:id/availability?date=YYYY-MM-DD` that returns hourly free time slots for a room on a given date (00:00–24:00 UTC), with 404 for unknown room and 400 for missing/invalid date.

## Non-goals
- No changes to `src/store.ts` data structures (it will be replaced by INFRA-140)
- No persistence, no authentication, no rate limiting
- No timezone support beyond UTC (dates are always UTC)

## Assumptions and open questions
- BLOCKING: Should the response format be `{ slots: { startsAt, endsAt }[] }` or `{ available: [...] }`? **Assumption:** use `{ slots: { startsAt: string, endsAt: string }[] }` for consistency with booking payloads.
- BLOCKING: Should slots that are partially booked be excluded entirely, or split? **Assumption:** hourly granularity — a slot is either fully free (no overlap with any booking) or not returned. Since bookings can start/end at any minute, a 1-hour slot is free only if no booking overlaps it at all.
- assumption: Day boundaries are 00:00:00Z to 24:00:00Z (exclusive) of the given date. A booking at 23:30–00:30 next day overlaps the 23:00–24:00 slot of the first day.
- assumption: Validation follows existing pattern — `ValidationError` thrown and caught in route (legacy style), since migrating to `Result` is out of scope for this endpoint.

+import type { Booking } from "../store.js";
+import { overlaps } from "./overlap.js";
+
+export default function computeAvailability(
+  roomId: string,
+  date: string,
+  bookings: Booking[]
+): { startsAt: string; endsAt: string }[] {
+  const roomBookings = bookings.filter((b) => b.roomId === roomId);
+  const freeSlots: { startsAt: string; endsAt: string }[] = [];
+
+  for (let hour = 0; hour < 24; hour += 1) {
+    const startHour = hour.toString().padStart(2, "0");
+    const endHour = (hour + 1).toString().padStart(2, "0");
+    const slotStart = `${date}T${startHour}:00:00Z`;
+    const slotEnd = `${date}T${endHour}:00:00Z`;
+
+    const hasOverlap = roomBookings.some((booking) =>
+      overlaps(slotStart, slotEnd, booking.startsAt, booking.endsAt)
+    );
+
+    if (!hasOverlap) {
+      freeSlots.push({ startsAt: slotStart, endsAt: slotEnd });
+    }
+  }
+
+  return freeSlots;
+}
